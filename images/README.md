# Images

원본 이미지, 증강 이미지, 재라벨 후보를 다루는 작업 공간입니다.

이 디렉터리의 새 이미지/XML 산출물은 기본적으로 `.gitignore`에 의해 제외됩니다. 커밋에는 스크립트 재현에 꼭 필요한 메타데이터만 남기고, 대용량 이미지 묶음은 데이터셋 아카이브나 Release 자산으로 공유하는 것을 권장합니다.

주요 하위 디렉터리:

| 경로 | 설명 |
|---|---|
| `skyedge_vision/` | 원본 라벨링 작업 이미지 |
| `skyedge_vision_aug/` | 증강 이미지 작업 결과 |
| `skyedge_vision_relabel/` | 재라벨 후보 이미지 |
